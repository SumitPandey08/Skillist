# Phase 7 Plan 04: Agentic Worker Infrastructure

## Objective
Establish a scalable backend worker infrastructure using LangGraph and BullMQ to handle long-running, multi-step AI tasks.

## Proposed Changes

### 1. Agent Module (`backend/src/modules/agentic-ai/`)
Create the core agent logic:
- `base-agent.ts`: Defines the shared LangGraph state and configuration.
- `roadmap-agent.ts`: A specialized agent that can refine roadmaps (e.g., adding resources, checking for prerequisites).
- `index.ts`: Export the agent entry points.

### 2. Queue & Worker Configuration (`backend/src/worker.ts`)
- Register the `roadmapQueue`.
- Set up a worker that listens for roadmap generation/refinement requests and executes the LangGraph workflow.

### 3. API Bridge (`backend/src/modules/agentic-ai/agent.routes.ts`)
- Expose an endpoint for the Next.js frontend (or other services) to trigger agentic tasks.
- Register routes in `backend/src/modules/index.ts`.

### 4. Verification Logic
- **Worker Execution**: Ensure the worker can pick up a job from Redis and complete it.
- **Agent Reasoning**: Verify that LangGraph correctly traverses its nodes and produces the expected output.

## Step-by-Step Execution Plan

1. **Step 1: Agentic AI Module Setup**
    - Create `backend/src/modules/agentic-ai/base-agent.ts`.
    - Create `backend/src/modules/agentic-ai/roadmap-agent.ts`.

2. **Step 2: Queue & Worker Setup**
    - Modify `backend/src/worker.ts` to include the roadmap worker.
    - Implement the job processor to call the LangGraph agent.

3. **Step 3: Routing & API**
    - Create `backend/src/modules/agentic-ai/agent.routes.ts`.
    - Register the routes in `backend/src/modules/index.ts`.

4. **Step 4: Verification**
    - Run the backend and worker in dev mode and push a mock job to verify end-to-end connectivity.

## Success Criteria
1. Backend worker successfully processes jobs from the `roadmap-queue`.
2. LangGraph agent generates a structured response and updates the DB (via Prisma).
3. The system can handle concurrent job requests without data corruption.
