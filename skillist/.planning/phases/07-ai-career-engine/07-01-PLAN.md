# Phase 7 Plan 01: DB Schema Sync & Roadmap Data Layer

## Objective
Establish the necessary database structure and basic server-side logic to support AI-generated career roadmaps and student progress tracking.

## Proposed Changes

### 1. Database Schema (`src/db/schema.ts`)
Add the following tables to sync with the existing Prisma backend models:
- `roadmaps`: `id`, `studentId`, `targetRole`, `description`, `progress`, `createdAt`, `updatedAt`.
- `roadmapSteps`: `id`, `roadmapId`, `title`, `description`, `skillId`, `status` (pending, in_progress, completed), `order`, `createdAt`, `updatedAt`.
- `mockInterviews`: `id`, `studentId`, `role`, `score`, `feedback`, `status`, `createdAt`, `updatedAt`.
- `notifications`: `id`, `userId`, `type`, `title`, `message`, `isRead`, `createdAt`, `updatedAt`.

### 2. Server Actions (`src/app/dashboard/student/_actions.ts`)
Implement core CRUD operations for roadmaps:
- `getStudentRoadmap`: Fetches the current active roadmap for a student.
- `updateRoadmapStepStatus`: Allows students to manually toggle step completion.
- `deleteRoadmap`: Removes an existing roadmap (to allow for regeneration).

### 3. Verification Logic
- **Schema Validation**: Ensure `npm run db:push` executes without errors.
- **Data Integrity**: Verify that roadmap steps are correctly linked to students via roadmaps.

## Step-by-Step Execution Plan

1. **Step 1: Schema Update**
    - Modify `src/db/schema.ts` to include the four new tables.
    - Ensure all references (especially `student_id` and `skill_id`) are correctly defined with cascades.

2. **Step 2: Database Migration**
    - Run `npx drizzle-kit push` (or the equivalent project script) to update the database.

3. **Step 3: Server Actions Implementation**
    - Create/Update `src/app/dashboard/student/_actions.ts`.
    - Implement `getStudentRoadmap` and `updateRoadmapStepStatus`.

4. **Step 4: Verification**
    - Write a temporary test script or use a manual check to ensure a roadmap can be inserted and queried.

## Success Criteria
1. `npm run db:push` (or similar) succeeds.
2. `getStudentRoadmap` correctly returns data for a given `studentId`.
3. Database constraints prevent orphan roadmap steps.
