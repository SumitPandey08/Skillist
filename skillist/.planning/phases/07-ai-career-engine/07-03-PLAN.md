# Phase 7 Plan 03: Student Roadmap UI & Progress Tracking

## Objective
Provide students with a visual representation of their career roadmap and the ability to track their progress towards their target role.

## Proposed Changes

### 1. Roadmap UI Component (`src/components/dashboard/student/roadmap-section.tsx`)
Create a new component that:
- Displays the current `targetRole` and overall `progress` bar.
- Lists all `roadmapSteps` in order.
- Provides a checkbox or toggle for students to mark steps as `completed`.
- Displays an empty state with a "Generate Roadmap" button and a target role input field if no roadmap exists.

### 2. Dashboard Integration (`src/app/(dashboard)/candidate/page.tsx`)
- Update the candidate dashboard to fetch and display the `RoadmapSection`.
- Use the `getStudentRoadmap` server action to load initial data.

### 3. Verification Logic
- **UI Responsiveness**: Ensure the roadmap looks good on mobile and desktop.
- **State Management**: Verify that clicking a status toggle immediately updates the progress bar and persists to the DB.

## Step-by-Step Execution Plan

1. **Step 1: Roadmap Component Implementation**
    - Create `src/components/dashboard/student/roadmap-section.tsx`.
    - Implement the "Generate Roadmap" form (role input + submit).
    - Implement the "Roadmap View" (progress bar + step list).

2. **Step 2: Dashboard Integration**
    - Modify `src/app/(dashboard)/candidate/page.tsx`.
    - Integrate the `RoadmapSection` component.

3. **Step 3: Verification**
    - Manually verify the end-to-end flow: input role -> wait for AI -> view roadmap -> toggle steps.

## Success Criteria
1. Student can input a target role and see a generated roadmap.
2. Toggling a step as "completed" updates the progress bar visually.
3. Roadmap UI handles loading states gracefully.
