# Phase 8 Plan 03: AI Interview Agent (Dynamic Questions & Logic)

## Objective
Implement the core AI logic that drives the interview, generating relevant questions and providing an adaptive, professional experience.

## Proposed Changes

### 1. AI Interview Utility (`src/lib/ai/interview.ts`)
Create a new utility `getNextInterviewQuestion` that:
- Accepts `interviewId`, `role`, and `history` (previous messages).
- Constructs a prompt that enforces a professional interviewer persona.
- Analyzes the conversation state (Introduction, Technical, Behavioral, Closing).
- Generates a follow-up or a new topic based on the candidate's last answer.

### 2. Server Action (`src/app/dashboard/student/_actions.ts`)
Update `addInterviewMessage` to trigger the AI turn:
- After saving the candidate's message, call `getNextInterviewQuestion`.
- Save the AI's response to the database as an 'interviewer' message.
- Return the AI's message to the frontend for immediate display.

### 3. Verification Logic
- **Conversation Flow**: Verify that the AI correctly transitions from introduction to technical questions.
- **Context Awareness**: Ensure the AI refers to previous answers when appropriate (e.g., "You mentioned X earlier...").

## Step-by-Step Execution Plan

1. **Step 1: Interview AI Logic**
    - Create `src/lib/ai/interview.ts`.
    - Implement the prompt engineering for the "Interviewer" persona.
    - Set up OpenAI chat completion with a focus on conversational flow.

2. **Step 2: Server Action Update**
    - Modify `addInterviewMessage` in `src/app/dashboard/student/_actions.ts` to be a multi-step action.
    - Integrate the `getNextInterviewQuestion` call.

3. **Step 3: Verification**
    - Manually test the conversation flow in the UI to ensure the AI responds logically.

## Success Criteria
1. The AI provides a welcoming introduction for the specific role.
2. The AI asks technical questions relevant to the candidate's background and the role.
3. The conversation history is correctly preserved and used for context.
