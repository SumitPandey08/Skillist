# Phase 8 Plan 02: Real-time Speech-to-Text & Interview UI

## Objective
Implement an immersive, real-time interview interface that handles voice transcription and provides immediate visual feedback to the student.

## Proposed Changes

### 1. Interview UI Component (`src/components/dashboard/student/mock-interview.tsx`)
Create a new component that includes:
- **Audio Waveform**: Visual feedback when the student is speaking (framer-motion).
- **Transcription Display**: Real-time display of the transcribed answer using Web Speech API.
- **Controls**: "Start Interview", "Next Question", "Complete" buttons.
- **Conversation Log**: Scrollable view of previous questions and answers.

### 2. Speech Hook (`src/hooks/use-speech.ts`)
Implement a custom hook to wrap the `webkitSpeechRecognition` API (standard for modern browsers):
- Methods: `startListening`, `stopListening`, `resetTranscript`.
- State: `transcript`, `isListening`, `error`.

### 3. Dashboard Integration (`src/app/(dashboard)/candidate/mock-interview/page.tsx`)
Create a dedicated page for the mock interview experience:
- Fetches initial interview metadata.
- Renders the `MockInterview` component.

## Step-by-Step Execution Plan

1. **Step 1: Speech Hook Implementation**
    - Create `src/hooks/use-speech.ts` with browser API checks.
    - Ensure it handles continuous speech and resets correctly between turns.

2. **Step 2: Mock Interview Component**
    - Create `src/components/dashboard/student/mock-interview.tsx`.
    - Build the waveform visualization using CSS and Framer Motion.
    - Integrate the speech hook into the UI.

3. **Step 3: Page Layout**
    - Create `src/app/(dashboard)/candidate/mock-interview/page.tsx`.
    - Ensure basic routing and auth are respected.

4. **Step 4: Verification**
    - Manually test speech recognition and message persistence in the UI.

## Success Criteria
1. Web Speech API correctly transcribes spoken words in the browser.
2. The UI shows an active waveform when `isListening` is true.
3. Transcripts are correctly displayed and ready for persistence.
