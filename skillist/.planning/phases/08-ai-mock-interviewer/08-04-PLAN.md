# Phase 8 Plan 04: Performance Analysis & Feedback Visualization

## Objective
Implement the final evaluation logic to analyze the mock interview transcript and provide the student with detailed, actionable feedback.

## Proposed Changes

### 1. Analysis Utility (`src/lib/ai/interview.ts`)
Add `analyzeInterviewPerformance` that:
- Accepts the full conversation history and target role.
- Evaluates the candidate across:
    - **Technical Competence**: Accuracy of answers.
    - **Communication**: Clarity and structure.
    - **Behavioral Fit**: STAR method usage and soft skills.
- Generates a final score (0-100) and 3-5 specific improvement points.

### 2. Feedback UI Component (`src/components/dashboard/student/interview-feedback.tsx`)
Create a new component to visualize the results:
- **Score Card**: Large display of the overall score.
- **Categorical Breakdown**: Simple bars or icons for Tech/Communication/Behavioral.
- **Actionable Tips**: List of specific things the student did well and what they can improve.
- **Next Steps**: Link to the relevant part of their Career Roadmap (if applicable).

### 3. Server Action Update (`src/app/dashboard/student/_actions.ts`)
Update `completeMockInterview`:
- Trigger `analyzeInterviewPerformance`.
- Save the score and feedback text to the `mockInterviews` table.

### 4. Page Routing
- Update the mock interview page to redirect to a results view once completed.

## Step-by-Step Execution Plan

1. **Step 1: Analysis AI Logic**
    - Implement `analyzeInterviewPerformance` in `src/lib/ai/interview.ts`.
    - Use Zod for structured evaluation output.

2. **Step 2: Server Action Update**
    - Modify `completeMockInterview` to include the AI analysis step.

3. **Step 3: Feedback UI**
    - Create `src/components/dashboard/student/interview-feedback.tsx`.

4. **Step 4: Verification**
    - Complete a full interview flow and verify the final feedback display.

## Success Criteria
1. The AI correctly summarizes strengths and weaknesses based on the conversation.
2. The final score reflects the quality of the candidate's answers.
3. The feedback UI is visually distinct and helpful.
