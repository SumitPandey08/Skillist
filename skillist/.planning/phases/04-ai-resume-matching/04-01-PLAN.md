<task type="auto">
  <name>Task 1: Update Database Schema for AI, Background & Applications</name>
  <files>src/db/schema.ts</files>
  <action>
    - Add `jobVector` column to the `jobs` table: `vector("job_vector", { dimensions: 1536 })`.
    - Create an `experience` table:
      - `id`: primary key (nanoid).
      - `studentId`: references `students.id`.
      - `title`, `company`, `location`, `description`: text.
      - `startDate`, `endDate`: timestamp.
    - Create an `education` table:
      - `id`: primary key (nanoid).
      - `studentId`: references `students.id`.
      - `school`, `degree`, `field`: text.
      - `graduationDate`: timestamp.
    - Create an `applications` table to track student applications to jobs.
    - Fields for `applications`:
      - `id`: primary key (nanoid).
      - `studentId`: references `students.id`.
      - `jobId`: references `jobs.id`.
      - `status`: text (e.g., 'pending', 'reviewed', 'accepted', 'rejected').
      - `matchScore`: integer (0-100).
      - `skillScore`, `expScore`, `projScore`, `potentialScore`: integers (each 0-100).
      - `analysis`: text (AI-generated reasoning for the score).
      - `createdAt`, `updatedAt`: timestamps.
    - Export the new tables and their relations.
    - Run migration using `npx drizzle-kit push`.
  </action>
  <verify>
    <automated>npx drizzle-kit check</automated>
  </verify>
  <done>Database schema updated with job vectors, background tables, and application tracking.</done>
</task>
