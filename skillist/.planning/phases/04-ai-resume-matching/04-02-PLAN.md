  <action>
    - Create `uploadResume(formData: FormData)` server action.
    - Logic:
      1. Extract File from FormData.
      2. Upload to Supabase Storage `resumes` bucket.
      3. Extract raw text from the PDF using `pdf-parse`.
      4. Call `extractResumeData(text)` from `lib/ai/parser.ts`.
      5. Update DB:
         - Clear old experience/education for the student (optional, or merge).
         - Insert new skills, experience, and education records.
      6. Generate a new embedding using `generateEmbedding` for the combined profile text.
      7. Update `students.skillVector` with the new embedding.
  </action>
