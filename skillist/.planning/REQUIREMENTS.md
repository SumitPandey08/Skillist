# Requirements

## v1 Requirements

### Authentication
- [x] **AUTH-01**: User can create a student or company account using email/password or OAuth.
- [x] **AUTH-02**: User can manage their profile, settings, and session state.

### Student Dashboard
- [x] **STU-01**: Student can track their skills, projects, and certifications with progress indicators.
- [x] **STU-02**: Student can build and publicly share a unified portfolio hub.
- [x] **STU-03**: Student can generate an ATS-optimized resume tailored to a specific job description.

### Company Dashboard
- [x] **COMP-01**: Company can post and manage job listings with explicit skill requirements.
- [x] **COMP-02**: Company can view the candidate pipeline and basic applicant details.

### External Integrations
- [x] **EXTERNAL-STATS-01**: Student can link and display verifiable stats from GitHub, LeetCode, and Codeforces.

## v2 Requirements

### Agentic Automation
- [ ] **AGENT-01**: AI agent can auto-schedule interviews with top candidates.
- [ ] **AGENT-02**: AI agent can send personalized follow-up emails and missing-skill notifications.

### Advanced Career Engine
- [ ] **CAREER-01**: System can generate step-by-step career learning roadmaps based on the user's skill gaps.
- [ ] **CAREER-02**: System can proactively recommend jobs and highlight missing skills required for those roles.

### Interview System
- [ ] **INT-01**: Student can perform real-time, voice-based mock interviews and receive AI-driven feedback.
- [ ] **INT-02**: Company can manage interview stages, scheduling, and feedback within the platform.

### Business & Analytics
- [ ] **BIZ-01**: Company can view advanced hiring analytics including time-to-hire, candidate quality, and conversion rates.
- [ ] **BIZ-02**: System supports processing payments for tiered student and company subscription plans.

## Out of Scope
- [Generic Job Board Listing] — We are not building a standard manual job board; the platform's core is the AI-driven skills matching.
- [University Portal Features] — While listed as an optional expansion, university-level monitoring and placement support are deferred to a post-v2 milestone to maintain focus on the core dual-sided marketplace.
