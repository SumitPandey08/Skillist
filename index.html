Skillist Workspace Architecture

Skillist is a highly intelligent, skill-driven career guidance and job matching platform. This project utilizes a multi-layered workspace consisting of a Next.js 16 frontend, an Express-powered backend API, background queue processing, and a relational database with AI vector search extensions.

2. The Backend-Proxy Drizzle Client (db/index.ts)

Instead of performing direct DB queries or invoking custom server actions, Skillist utilizes a simulated Drizzle ORM client. When developers write code to access tables:

// The code reads like standard ORM queries: const students = await db.query.students.findMany(); // Under the hood, db.query is mapped to mockQuery in db/index.ts: const mockQuery = (endpoint: string) => ({ findMany: async (options: any) => { const data = await fetchFromBackend(endpoint); return Array.isArray(data.items) ? data.items : data; } });

The requests are processed by src/lib/api-server.ts, which injects Clerk OAuth tokens into the headers as authorization metadata before sending it to the backend server.

RAG & AI Agent Engine

Skillist deploys a state-of-the-art AI layer combining Retrieval-Augmented Generation (RAG) using vector similarity queries, structured schema parsers, and multi-agent workflow orchestration.

1. AI Orchestrator & Model Stack

2. Vector Embeddings & Similarity Matching (RAG)

To perform job recommendation and applicant matchmaking, Skillist converts text content into vector embeddings and runs cosine similarity queries directly inside Supabase PostgreSQL using pgvector.

Step A: Embedding Generation
When a job is created or a student updates their skills profile, text metadata is compiled and converted to a 768-dimension vector using the Gemini text-embedding-004 API model:

const result = await model.embedContent( text.replace(/\n/g, " ") ); const vectorArray = result.embedding.values;

Step B: Vector Database Search
Prisma doesn't natively expose distance vector computations. The system runs raw SQL queries using the cosine distance operator <=> to return matches sorted by score:

SELECT id, title, 1 - (job_vector <=> ( SELECT skill_vector FROM students WHERE id = $1 )) as "matchScore" FROM jobs WHERE job_vector IS NOT NULL ORDER BY job_vector <=> ( SELECT skill_vector FROM students WHERE id = $1 )
Cosine Similarity Operator (<=>)

In PostgreSQL, the <=> operator calculates cosine distance. Subtracting this from 1 converts the distance calculation into a cosine similarity metric:

• 1.0 represents an exact match.
• 0.0 represents complete perpendicularity.

This is used to instantly query and sort hundreds of open job postings against a student's parsed skill vector.

3. Stateful Multi-Agent Workflows (LangGraph)

Complex AI analysis pipelines are orchestrated using stateful graphs (LangGraph). An example is the candidate-to-job matching pipeline inside backend/src/lib/ai/matcher.ts:

Graph State Definition
Maintains properties across running agent nodes:

const MatchState = Annotation.Root({ jobId: Annotation<string>, student: Annotation<any>, job: Annotation<any>, skillScore: Annotation<number>, externalStats: Annotation<any>, scores: Annotation<ComponentScores>, totalScore: Annotation<number>, });

Node Execution Workflows
Compiles state steps into sequential edges:

const workflow = new StateGraph(MatchState) .addNode("collector", dataCollector) .addNode("scorer", aiScorer) .addNode("finalizer", finalizer) .addEdge(START, "collector") .addEdge("collector", "scorer") .addEdge("scorer", "finalizer") .addEdge("finalizer", END);

4. AI & Agent Directory File Layout

AI source files are organized into two primary folders:

📁 /backend/src/lib/ai

Shared AI Core Utilities & Functions:

• embeddings.ts: Connects to Gemini's text-embedding-004 model to convert text strings to vector float arrays.
• matcher.ts: Executes the LangGraph matching graph, compiling skill overlaps and candidate portfolios.
• resume.ts: Parses PDF files, structures data via Zod, and scores ATS compatibility matches.
• roadmap.ts: Generates customized roadmap paths with documentation resources and learning checkpoints.
• openai.ts: Configures raw Gemini API structured JSON outputs using zodToJsonSchema converters.

📁 /backend/src/modules/agentic-ai

Agent Pipelines & Queue Controllers:

• base-agent.ts: Configures the base LangChain model configurations and global state contexts.
• career-agent.ts: Formulates behavioral assessment questions and interprets profile matches.
• interviewer-agent.ts: Builds interactive questions for conducting mock technical interviews.
• roadmap-agent.ts: Analyzes prerequisite skills and adjusts roadmap node difficulties.
• agent.worker.ts: BullMQ background consumer that processes AI tasks asynchronously.
